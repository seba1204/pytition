# Configuration

There are two types of configurations:

- [**Initial configuration**](./env_var/index.md) : during installation, via configuration files, or env var: a few settings that must be configured before anything else (database access, data folders, etc.)
- [**Instance configuration**](./site_conf/index.md) : when the app is running, you wan tweak it from the web interface (site name, security rules, etc.)

If you plan to deploy Pytition in production, please also refer to the [Production Configuration](./prod.md) page.
