# Initial configuration

Since Pytition is based on Django, you can configure a LOT of things using variables. Usually, you have to edit a `settings.py` file, but to simplify things, Pytition can also read a `.env` file or environment variables.

To simplify the documentation, we have organized the section on parameter variables into three parts:

- **Basics**: the most common variables you will want to modify for a quick and standard installation
- **All**: all variables if you are looking for a specific one, or just want to take a look at what is available
- **Under the hood**: explains the logic behind reading variables
